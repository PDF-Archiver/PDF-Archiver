# PDF Archiver

@Metadata {
    @TechnologyRoot
}

A document archive whose database is the set of filenames.

## Overview

PDF Archiver files scanned documents under one convention:

```
2024-03-11--stromabrechnung-eon__rechnung_strom.pdf
```

Date, description and tags are the filename. There is no index, no sidecar, no
proprietary store — which is the whole point. The archive keeps working in
Finder, in Files.app, in Spotlight, and in whatever tool exists in ten years,
because a folder of PDFs is not a format anyone has to support.

Everything the app does follows from that. Filing a document means naming it.
Searching means matching filenames. Syncing means whatever iCloud Drive or your
own folder already does. And the suggestions the app offers when you file
something are built from the names you have already chosen, so the archive
teaches the app its own vocabulary rather than the other way round.
