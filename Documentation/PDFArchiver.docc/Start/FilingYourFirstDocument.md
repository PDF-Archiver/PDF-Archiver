# Filing your first document

From a piece of paper to a named PDF in the archive.

## Overview

The app has two folders: an **untagged** one where everything arrives, and the
**archive**, where documents live under their final name in a folder per year.
Filing a document is the step between the two, and it is always the same step —
give it a date, a description and tags.

### 1. Get the document in

Scan it with the camera, drop a PDF onto the window, or share it from another
app. Anything that arrives lands in the untagged folder with a placeholder name.
A document dropped straight into that folder by a desktop scanner or Files.app
counts too; the app watches the folder rather than requiring you to use its
import buttons.

### 2. Open it in the tagging form

The untagged list shows what is waiting. Opening an entry shows the document
next to three fields: date, description, tags.

If Apple Intelligence is on and the document has readable text, those fields
arrive filled in — see <doc:TurningOnAppleIntelligence>. The suggestions come
from your own archive, so a household that files `rechnung` and `steuerrelevant`
gets those words back, not generic ones.

### 3. Correct what is wrong, then save

The suggestions are a starting point and will not always be right. Fix the
fields and save.

Saving renames the file and moves it into `Archive/<year>/`. Nothing else
happens — there is no database write, because the name *is* the record. What you
typed is exactly what a future you will find in Finder.
